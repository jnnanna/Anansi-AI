# Anansi-AI — Prototype FR → Wolof TTS (hybride)

But : pipeline prototype pour traduire du français vers le wolof, adapter le texte et générer de l'audio via un TTS finetuné.

Contenu :
- notebook Colab pour prototypage
- scripts Python pour préparation, entraînement et inférence
- support pour dataset HuggingFace + fusion avec dataset local (Drive)
- instructions en français

Prérequis et usage détaillés dans docs/USAGE_FR.md
